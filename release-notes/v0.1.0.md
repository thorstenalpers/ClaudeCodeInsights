### What's Changed

**First release**

- **Overview** — sessions, turns, tokens by class and active days from the transcripts
  under `~/.claude/`. Cache reads get their own figure instead of disappearing into a
  total.
- **Sessions** — every conversation in a sortable, searchable table, with the activity it
  was mostly spent on derived from its tool calls. Codex sessions are read as well.
- **Transcript replay** — messages, thinking blocks and tool calls paired with their
  results.
- **Projects** — analyze, tidy and remove the projects Claude Code has registered.
- **RTK stats** — the token savings RTK reports, next to the usage they relate to.
- **Assistant** — answers questions about your usage. Its default source is the Claude
  Code binary on this machine; hosted models are used only when you pick one, and API
  keys stay in the Windows credential store.

Everything stays local. The app reads `~/.claude/` and writes only to
`%LocalAppData%\ClaudeAdmin`.

Costs are estimates from published API prices and do not apply to subscription plans.
The installer is not code-signed yet, so Windows SmartScreen may ask for confirmation.
